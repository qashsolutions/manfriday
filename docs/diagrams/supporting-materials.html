Data handling, security, and quota statement

Man Friday (manfriday.app) · Google Cloud project 845649489196 (man-friday-508102) · Operated by Qash Solutions · 12 September 2026 · Contact: admin@manfriday.app

1. What Man Friday is

Man Friday is a web application for solo software builders. It reads the user's own product website, drafts short vertical videos about that product, and shows them in a swipe feed. The user approves the videos they like and schedules them. Approved videos can be published to the user's own YouTube channel as Shorts. The app is public (anyone can sign up free, no card), commercial (subscriptions), and web-only.

Google is used only to connect a YouTube channel for publishing. App identity is handled by Clerk (passkeys, email, Google or GitHub sign-in through Clerk). A YouTube connection is never a login.

4. User control and revocation

  • Consent: Google's consent screen shows both scopes; the user can cancel. The app does not request incremental or additional scopes later.
  • Disconnect: Settings › Connected accounts › Disconnect. The app calls Google's revoke endpoint, sets the stored tokens to empty immediately, and deletes remaining metadata within 7 days.
  • Delete account: Settings › Your data › Delete account removes the account, brand briefs, generated videos, and all connected-account records.
  • Google-side revocation: the user can revoke Man Friday at any time at myaccount.google.com › Security › Third-party access; after that the stored token stops working, the app can no longer upload or read anything, and the user must reconnect explicitly.
  • Published videos stay on the user's channel in all cases; the app never deletes YouTube content.

5. Security overview

AreaControl
AuthenticationClerk; passkeys and TOTP available; sessions expire after 60 minutes of inactivity.
Connect gateA passkey or 2FA must be enabled on the Man Friday account before any social account (YouTube, TikTok) can be connected.
Token handlingTokens live only in the Convex database (encrypted at rest by the platform) and are used only inside server-side actions. They are never returned to the browser, never logged, and never given to the render worker.
SecretsOAuth client secret and API keys are stored as Convex / Vercel environment variables; they are not in source control.
TransportHTTPS everywhere; OAuth redirect URI is the fixed https://manfriday.app callback registered in the Google Cloud project.
Least privilegeTwo scopes only; endpoints listed in section 2 only; per-account scheduler so one user cannot exhaust the shared quota.
Logging and monitoringServer logs never include tokens or YouTube data; PostHog product analytics receives no YouTube data.
Automated compliance guardA test suite (validation/compliance) runs on every code push, on every pull request, and weekly against the live site. It fails the build if the code requests any scope or calls any endpoint outside those declared here, if a public function could return a token, if the schedule gate is weakened, or if the privacy policy or terms lose their YouTube disclosures. Changing the declared use case requires prior written notice to YouTube.
User noticesIf Google stops accepting the app's access (expired or revoked), Settings and the publish queue tell the user that posting is paused and offer Reconnect; failed uploads show a plain-language reason. The app never retries an upload on its own.
